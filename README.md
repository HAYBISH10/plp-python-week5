# plp-python-week5
# Assignment: Countdown, Guessing Game & Loop Patterns

This assignment practices Python `while` loops, `for` loops, conditionals, counters, and repetition.

## Files

* `countdown.py` - Uses a `while` loop to count down from a user-provided number and prints "Blast off!" when the countdown finishes.
* `guess_game.py` - Uses a `while` loop, conditionals, and an attempt counter to create a number guessing game.
* `spell_it_out.py` - Uses `for` loops to print the letters of a word individually and then number each letter.
* `screenshots/` - Contains screenshots showing the required program runs.

## When would you use a while loop instead of a for loop?

I would use a `while` loop when I do not know exactly how many times the loop needs to run and want it to continue until a condition becomes false. A `for` loop is usually better when I know what data or sequence I want to go through, such as each letter in a word.
